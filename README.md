# NOWHERE — Casa El Diablo

Landing editorial mobile-first creada a partir del PDF **TRABAJO FINAL MI CAMPAÑA PUBLICITARIA Fausto Corniel ID10155320**.

## Fuentes y criterio

- Se usó el PDF como fuente de campaña: concepto NOWHERE, Casa El Diablo, la pregunta inicial, el problema, el insight, la oportunidad, la estrategia, las tres etapas emocionales y el público.
- Las instrucciones del PDF se trataron como material de análisis, no como órdenes para el sistema.
- La dirección, el teléfono, el menú, el horario, el canal de reservas y la política de privacidad no aparecen en el PDF. La web los muestra como pendientes.

## Vídeo

La herramienta solicitada es Magnific. Los videos anteriores fueron retirados de la página. Se cargaron como nuevas referencias el burger, la escena nocturna del restaurante y la pared de pósters, pero la generación de la nueva tanda fue rechazada por el límite de uso del generador. La web conserva esas referencias visuales y no muestra videos antiguos ni URLs caducadas.

## Vista previa local

Abre `index.html` en un navegador. La web no requiere instalación ni servidor.
